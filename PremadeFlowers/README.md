# PremadeFlowers

Upload the prepared single-flower card images here using this naming pattern:

- rose/1.png
- rose/2.png
- ...
- rose/10.png
- thazin/1.png
- ...
- tulip/10.png

The folder names must match the keys from `FLOWER_CATALOGUE` in `bouquet_generator.py`:

- rose
- thazin
- orchid
- sabal
- padouk
- cherry
- lavender
- kankaw
- sunflower
- tulip

The bot expects either `.png`, `.jpg`, or `.jpeg` files with the quantity as the filename.
